# SNS空間の言論空間 ～対立的・有害表現の拡散分析～

Bluesky上の投稿・リプライ・リポスト・フォロー関係を取得し、ユーザーの行動傾向と
対立的・有害表現の特徴を分析して、拡散ネットワーク図とグラフでGUI上に表示するツールです。

授業の一環で作った、Streamlitで動くWebアプリです。

> **APIキー・パスワードについて**: このリポジトリには、鍵やパスワードを含めていません。
> Blueskyのハンドル・アプリパスワード・Gemini APIキーは、アプリを起動したあと、画面左のサイドバーに自分で入力します。
> 分析結果（`saved_runs/`）は、他人の投稿データを含むため、公開しません。

## できること

1. 特定の投稿を起点に、リプライ・リポストしたユーザーを収集し、拡散ネットワーク図として表示
2. （オプション）キーワード/ハッシュタグ検索で投稿・ユーザーを追加収集
3. 各ユーザーを行動傾向で「投稿型・拡散型・返信型・閲覧型」に分類（ルールベース）
4. Gemini APIで各ユーザーの投稿の「対立的表現の強さ」を判定し、タイプごとに「高い/低い」の2群に分割
5. 「対立的表現が高い」ユーザーの投稿について、攻撃的表現・排除要求・処罰要求・暴力肯定表現・陰謀論的表現の出現率を集計
6. 結果をテーブル・グラフ・ネットワーク図としてGUIに表示し、CSV/JSONで保存可能

## セットアップ

### 1. 必要なもの

- Python 3.10以上
- Blueskyアカウント
- Google AI Studio のアカウント（Gemini APIキー用、無料枠あり）

### 2. パッケージのインストール

```bash
cd bsky_conflict_analyzer
pip install -r requirements.txt
```

### 3. Bluesky アプリパスワードの取得

1. https://bsky.app にログイン
2. 設定（Settings） → プライバシーとセキュリティ（Privacy and Security） → アプリパスワード（App Passwords）
3. 「新規追加」から新しいアプリパスワードを発行し、控えておく
   ※ 通常のログインパスワードは使わないこと（セキュリティ上、アプリ専用パスワードを使う設計になっています）

### 4. Gemini APIキーの取得

1. https://aistudio.google.com/apikey にアクセス
2. Googleアカウントでログインし、「Create API key」でキーを発行
3. 無料枠には1分あたり・1日あたりのリクエスト数制限があります。本アプリはバッチ処理と待機時間で
   この制限に配慮した設計にしていますが、大量データを扱う場合は制限に達する可能性があります。

### 5. アプリの起動

```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。左のサイドバーにBlueskyのハンドル・
アプリパスワード・Gemini APIキーを入力し、収集方法を選んで「分析を実行」を押してください。

## 使い方のヒント

- 対象投稿のURLは `https://bsky.app/profile/xxx/post/yyy` の形式で入力してください
- 初めて使うときは、サイドバーの各スライダーを小さめの値（例: 最大リプライ数30、対象ユーザー数10）
  にして、無料枠内で動作確認することをおすすめします
- 分析結果は「保存/出力」タブからJSON/CSVで保存でき、次回はサイドバーの
  「過去の結果を読み込む」から再表示できます（APIを再度呼ばずに済みます）

## 設計についてのメモ

- **行動タイプの分類**は、各ユーザーの直近投稿（最大30件）から
  オリジナル投稿率・リプライ率・リポスト率を計算し、最も高い比率のタイプに割り当てるルールベース方式です。
  いずれの活動も少ないユーザーは「閲覧型」とみなします。
- **対立的表現レベル**は、Gemini APIが各投稿につけた0〜100の対立表現スコアの平均値を、
  行動タイプごとの中央値で「高い/低い」に二分しています。
- **有害表現5種の出現率**は、「対立表現が高い」グループのユーザーの投稿における
  各カテゴリの出現率（該当投稿数 ÷ 分析対象投稿数）です。

## 既知の制約・注意点

- `atproto` パッケージのバージョンによっては、APIメソッドの呼び出し形式（引数の渡し方）が
  変わっている場合があります。エラーが出た場合はサイドバーの実行ログとエラーメッセージを確認し、
  `modules/bluesky_client.py` 内の該当箇所を該当バージョンのドキュメントに合わせて調整してください。
- Gemini APIの無料枠のレート制限（モデルやプランにより変動）に達するとエラーになることがあります。
  その場合は「対象ユーザー数上限」や「1ユーザーあたりの投稿数」を減らして再実行してください。
- 本ツールは学術研究目的で、対立的・有害な言論の拡散パターンを把握するためのものです。
  収集したデータの取り扱い（公開範囲、個人が特定される情報の扱いなど）については、
  所属機関の研究倫理指針に従ってください。
